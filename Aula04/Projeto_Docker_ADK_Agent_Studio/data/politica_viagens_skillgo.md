# Política de viagens da SkillGo

Viagens nacionais precisam de aprovação prévia do gestor responsável.

O limite de hospedagem é de R$ 450 por diária. Despesas acima desse valor
exigem justificativa documentada e aprovação da área financeira.

O colaborador deve guardar notas fiscais e comprovantes para a prestação de
contas. As despesas devem ser registradas até cinco dias úteis após o retorno.
